SessionBar v0.1 - market session clocks (New York / London / Tokyo)

START HERE:
  1. Double-click build.bat in this folder (sessionbar-app).
     It finds Visual Studio's CMake by itself, downloads JUCE 8 on
     the first run (needs internet), builds the app, and runs the
     core unit tests (expect: 107 checks, 0 failures).
  2. When it says DONE, double-click:
       build-app\app\SessionBar_artefacts\Release\SessionBar.exe
  3. The bar appears borderless and always-on-top with the three
     session cells - each city with its local time, OPEN / BREAK /
     CLOSED state, and a live countdown to the next open, break,
     resumption or close. Times use real daylight-saving rules.

Windows will probably show a blue SmartScreen prompt the first time
(unsigned app): More info -> Run anyway. Normal for free software.

One honesty note: exchange HOLIDAYS are not modeled in v0.1 - the
clock follows the regular Mon-Fri schedule only.

Then read README_TEST.md - it walks through the field tests:
the phone world-clock glance check, watching a countdown flip at
an open, Tokyo's lunch BREAK, the weekend countdown, docking and
Reserve screen space.

If the build fails, send Milo build-log.txt from this folder.
